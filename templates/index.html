STUDY MODE

01. Wired LAN

A local area network connects nearby devices. Switches commonly forward Ethernet frames; routers connect IP networks.

  • Identify end devices and network devices.
  • Know the purpose of a switch and router.

02. IP addressing

IPv4 addresses are 32 bits; IPv6 addresses are 128 bits. Address, prefix and gateway settings must match the network plan.

  • Example IPv4: 192.168.1.10
  • Example IPv6: 2001:db8::1

03. Reliability & security

TCP provides reliable ordered delivery. QUIC runs over UDP and integrates TLS 1.3 security.

  • Checksum can detect data errors.
  • Flow control protects the receiver.
